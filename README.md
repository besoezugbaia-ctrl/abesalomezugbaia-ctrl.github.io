# Abesalom Ezugbaia | Portfolio

A responsive personal portfolio website built with HTML, CSS and JavaScript.

**Live:** https://besoezugbaia-ctrl.github.io/abesalomezugbaia-ctrl.github.io/

## About

This is my personal portfolio, created after completing the **Front-End Development & SEO** course at Smart Academy (Feb 27 – Jul 7, 2026). It presents who I am, the services I offer, my projects and a way to get in touch.

## Features

- Responsive layout for desktop, tablet and mobile
- Mobile navigation with a hamburger menu
- Active navigation link highlighting on scroll
- Auto-playing image slider in the hero section
- Certificate preview with a full-size lightbox
- Projects section with Live and GitHub links
- Contact form with loading state and success modal

## Sections

1. Home
2. About Me (with certificate)
3. Services
4. My Projects
5. Get in Touch

## Built With

- HTML5
- CSS3 (Flexbox, Grid, custom properties, media queries)
- JavaScript (ES6, DOM manipulation, Fetch API, Intersection Observer)

## Run Locally

1. Clone the repository:
   `git clone https://github.com/besoezugbaia-ctrl/abesalomezugbaia-ctrl.github.io.git`
2. Open the project folder.
3. Open `index.html` in your browser (or use the Live Server extension in VS Code).

## Contact Form Setup

The contact form sends messages through [Formspree](https://formspree.io). To enable it, create a form there and paste its URL into the `FORM_ENDPOINT` constant in `app.js`.
